# Part 2.1 — HTML Layout

1. Put `index.html` in the repository root.
2. Keep `css/style.css` and `js/app.js` in their respective folders.
3. The page contains:
   - Header
   - Summary cards
   - Search input
   - Department, Status and Account Code filters
   - Rows-per-page selector
   - Responsive transaction table
   - Pagination
4. The table fields are based on the first eight columns of the `Transactions` table:
   - Transaction Number
   - Account Code
   - Particulars
   - Department
   - Estimated Amount
   - PR/SoW/ToR Number
   - DV Number
   - Status
